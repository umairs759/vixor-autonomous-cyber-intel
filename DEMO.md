# VIXOR Demo Script

1. Login as admin (seeded credentials).
2. Create a project and register a domain.
3. Verify domain ownership via DNS TXT or `.well-known` file.
4. Run discovery to populate assets (scope-guard enforced).
5. Launch a scan; observe live progress over WebSocket.
6. View findings with risk gauge, SHAP chart, deterministic narrative, and remediation.
7. Review regression statuses (NEW/RECURRING/REINTRODUCED/RESOLVED).
8. Review correlations and combined risk narratives.
9. Generate and download the PDF report.
10. Admin: manage users and audit logs.
